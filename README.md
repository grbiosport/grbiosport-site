# GR.BIOSPORT // Biosecurity Systems

Repositório oficial do ecossistema digital e portal web da **GR.BIOSPORT**, empresa especializada em engenharia sanitária, desinfecção quaternária ativa e certificação de biossegurança para tatames e pisos esportivos de alta densidade.

🌐 **Site Oficial:** [www.grbiosport.com.br](https://www.grbiosport.com.br)  
📱 **Instagram:** [@grbiosport](https://instagram.com/grbiosport)

---

## 🚀 Sobre o Projeto

Plataforma web desenvolvida para apresentar o protocolo clínico de higienização de 3 fases voltado para academias de artes marciais (com foco inicial em Jiu-Jitsu), garantindo retenção de alunos, segurança dérmica e blindagem de imagem para os dojôs na região da Barra da Tijuca e do Rio de Janeiro - RJ.

## 🛠️ Stack Tecnológica

* **Frontend:** HTML5, Tailwind CSS (CDN v3), Font Awesome Icons.
* **Tipografia:** Google Fonts (*Plus Jakarta Sans* & *JetBrains Mono*).
* **Hospedagem & DNS:** GitHub Pages + Registro.br (`www.grbiosport.com.br`).
* **Integrações:** Automação de conversão direta para atendimento comercial via WhatsApp.

## 📂 Estrutura do Repositório

* `index.html` — Página principal (Landing Page comercial com telemetria, comparativo e formulário).
* `politica.html` — Página dedicada à Política de Biossegurança e normas sanitárias ativas.
* `selo.html` — Apresentação oficial do Selo GR de Certificação de Excelência.
* `CNAME` — Configuração de apontamento para o domínio personalizado.
